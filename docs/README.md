## Como usar esta documentação

Antes de alterar a geração de escalas, disponibilidade, conflitos, publicação ou critérios de distribuição, consulte a especificação de produto e o ADR correspondente. Em caso de conflito, uma nova decisão deve ser registrada antes da implementação; não se deve alterar silenciosamente uma regra documentada.
